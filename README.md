# sopverify: SOP compliance checking from video

Given an **SOP** (steps with prerequisites), **2–3 expert demonstration videos** and a **new video** from the same fixed
camera, `sopverify` decides for every step whether it was **done**, **not done**, **done out of order** or **can't
tell**. It gives a timestamp and an evidence keyframe for each step, plus an overall **compliant / non-compliant / needs
review** verdict.

Core idea: **verify end-states, not actions.** From the demos it learns what the workspace looks like *after* each step.
It then detects when that end-state appears in the new video and checks the completion order against the SOP's
prerequisite graph. V1 is built and evaluated on [IMPACT v1.1](https://github.com/Kratos-Wen/IMPACT) (Model A angle
grinder reassembly, front view), but everything specific to one procedure lives in a *procedure package*
(`procedures/<name>/`). See [`spec.md`](spec.md) for the full specification.

**Status:** code for every milestone is in place and tested. The IMPACT procedure package is a **draft awaiting review**,
and GPU experiments run in the Colab notebooks. See [`docs/PROGRESS.md`](docs/PROGRESS.md).

## Quickstart (Google Colab, A100)

1. Open `notebooks/00_setup_colab.ipynb` in Colab (File → Open notebook → GitHub → `RohanSada/SOP-Verification`, branch
   `claude/nifty-mccarthy-5suut3`) and run it. It mounts Drive, installs the package and runs the fast tests.
2. `01_download_and_discover.ipynb` downloads the IMPACT annotations (8 MiB) and pulls only the 45 front-view videos and
   VideoMAEv2 features out of the large remote archives (HTTP range requests; no 20+ GiB downloads).
3. `02_extract_features.ipynb`: confirm the workspace crop, extract DINOv2 features (cached on Drive, resumable).
4. `03_run_experiments.ipynb`: experiments E0–E6, writes tables for `docs/RESULTS.md`.
5. `04_vlm.ipynb`: Qwen3-VL scorer and verifier (E7), in a fresh runtime with vLLM.
6. `05_app.ipynb`: Gradio app with a share link.

Data and caches live on Drive under `/content/drive/MyDrive/sopverify/{data,cache,runs,exports}`. Override them with
`SOPVERIFY_DATA_ROOT`, `SOPVERIFY_ANNOTATIONS`, `SOPVERIFY_CACHE`, `SOPVERIFY_RUNS`, `SOPVERIFY_EXPORTS` and
`SOPVERIFY_SCRATCH`.

## Local use (no GPU)

```bash
pip install -e ".[app,dev]"
```

```bash
python -m pytest -q -m "not data and not gpu"
```

```bash
sopverify procedure validate procedures/impact_reassembly_A
```

Everything that needs only annotations also runs locally: data summaries, ground truth, E0 and E1, and the app with the
time-prior scorer. Point `SOPVERIFY_ANNOTATIONS` at a clone of the IMPACT repo's `dataset/` folder:

```bash
git clone --depth 1 https://github.com/Kratos-Wen/IMPACT.git /tmp/IMPACT
```

```bash
SOPVERIFY_ANNOTATIONS=/tmp/IMPACT/dataset SOPVERIFY_RUNS=./runs sopverify eval -c configs/experiments/E0_oracle.yaml
```

## CLI

| Command | Purpose |
|---|---|
| `sopverify data summarize` | One row per pool execution (participant, expertise, duration, anomalies, PSR events, video/features) |
| `sopverify data download annotations\|sample\|videos\|features` | Whole small bundles (checksummed) or pool members from big bundles |
| `sopverify procedure validate <pkg> [--step-set grouped]` | Schema and DAG checks |
| `sopverify procedure render\|stats\|roi-preview <pkg>` | Graph SVG, completion-order statistics, crop-box preview |
| `sopverify features extract [--crop roi\|full] [--extractor shipped_videomaev2]` | Cache features for the pool |
| `sopverify run --execution <id>` or `--video clip.mp4` | Judge one video → `verdict.json`, evidence, `report.html` |
| `sopverify eval -c configs/experiments/E3_scorers.yaml [--set features.crop=full]` | Run an experiment |
| `sopverify tables --inject docs/RESULTS.md` | Aggregate runs into Markdown tables |
| `sopverify report --run runs/<run_id>` | Rebuild HTML reports |
| `sopverify app --share` | Gradio app |

## Layout

```
configs/            default.yaml, best.yaml, experiments/E0..E7
procedures/         impact_reassembly_A/ (procedure.yaml, sop.md, step_sets/, roi.yaml, vocab.yaml)
src/sopverify/      config · data/impact · procedure · video · features · state · temporal · compliance · vlm · report · eval · pipeline · cli · app
notebooks/          00–05 Colab notebooks (generated by scripts/build_notebooks.py)
docs/               DATA_NOTES · DECISIONS · PROGRESS · RESULTS · NEW_PROCEDURE
tests/              fast synthetic suite; @data (IMPACT annotations) and @gpu tests skip when unavailable
```

The **test-label firewall** (spec 9.1): only `sopverify.eval` reads annotations of judged videos. The pipeline accepts an
annotation-free `ExecutionRef` or a video path, and `tests/test_firewall.py` statically checks that inference packages
never import `sopverify.eval`.
